# THz-PCF Thesis Python Post-Processing

This repository contains the Python post-processing workflow used in my MSc thesis.

The numerical data were obtained from COMSOL Multiphysics and processed using Python in Jupyter Notebook.

The code was used to calculate and analyze:

- Effective refractive index
- Power fraction
- Total power fraction
- Relative sensitivity
- Effective mode area
- Numerical aperture
- Confinement loss
- Healthy-cancer effective-index difference (Δneff)
- Healthy-cancer relative-sensitivity difference (ΔRS)
- Core-diameter comparison
- Mesh-independence results

## Software

- Python
- Jupyter Notebook
- pandas
- NumPy
